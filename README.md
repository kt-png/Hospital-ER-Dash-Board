# 🏥 Hospital Emergency Room (ER) Dashboard | Power BI

## 📌 Project Overview

This project focuses on analyzing Hospital Emergency Room (ER) operations using Microsoft Power BI.

The objective is to analyze patient visits, admission patterns, waiting times, patient satisfaction, and department referrals through interactive visualizations and business intelligence reporting.

The dashboard helps understand hospital operational performance, identify busy periods, and generate insights that can support better resource planning and patient experience.

## 🎯 Project Objectives

- Analyze overall patient visits.
- Monitor average patient waiting time.
- Evaluate patient admission patterns.
- Understand patient demographics.
- Identify peak hours and busiest days.
- Analyze department-wise patient referrals.
- Monitor patient satisfaction.
- Develop an interactive dashboard for healthcare analytics.

## 📊 Key Performance Indicators (KPIs)

The dashboard focuses on four important metrics:

1. **Total Patients:** Overall number of patients visiting the emergency room.
2. **Average Wait Time:** Average time patients wait before receiving medical attention.
3. **Patient Satisfaction:** Average patient satisfaction score.
4. **Patient Admission:** Number of patients admitted to the hospital.
